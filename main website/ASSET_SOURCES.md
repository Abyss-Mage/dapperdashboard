## Production website portfolio migration — 2026-10-24

The current public portfolio HTML at https://dapperdetailing.ca/portfolio/ was inspected read-only. Eighteen unique image sources were prepared under assets/portfolio/portfolio-01.jpg through portfolio-18.jpg. portfolio-import.json records each exact source URL, originalSHA256 and localSHA256. JPEG outputs are EXIF-oriented, resized within1600px and metadata-stripped; they do not fabricate vehicle outcomes. No third-party stock imagery, fonts or partner marks were added.

These remain existing client-site references with their original ownership. Local availability does not establish permission for publication. The dashboard offers a reviewed import: title/alt/category/order and image-permission review precede publication. No application media records were inserted or automatically published by the preparation script. Both active public galleries read the database; historical static portfolio buttons were removed from the active homepage, and the original assets/licenses/evidence are retained.

The prepared source-photo archive is embedded privately in the Go content handler. Authorized content.manage requests can review it through /content/source-images; it is excluded from Next public assets. Publishing an imported photo creates the same scoped media/publication records as a normal upload. Anonymous access to drafts or the private migration archive is denied.
